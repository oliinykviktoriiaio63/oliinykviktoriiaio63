##  Мета лабораторної роботи

Засвоєння теоретичного матеріалу та набуття практичних навичок розв'язання задачі сортування заданої категорії елементів за допомогою різних алгоритмів сортування у двовимірних масивах.

## 1. Постановка задачі

1. Задано двовимірний масив (матрицю) цілих чисел A[m,n] або A[n,n], де m та n — натуральні числа (константи), що визначають розміри масиву. Виконати сортування цього масиву або заданої за варіантом його частини у заданому порядку заданим алгоритмом (методом). Сортування повинно виконуватися безпосередньо у двовимірному масиві **«на тому ж місці»**, тобто без перезаписування масиву та/або його частини до інших одно- чи двовимірних масивів, а також без використання спискових структур даних.
2. Розміри матриці m та n взяти самостійно в межах від 7 до 10.
3. При тестуванні програми підбирати такі вхідні набори значень матриці, щоб можна було легко відстежити коректність виконання сортування, і щоб ця коректність була протестована для всіх можливих випадків. З метою тестування дозволяється використовувати матриці меншого розміру.

Оскільки мій номер у списку - 17, моє завдання:

|№|Завдання|
|---|---|
|17|Задано двовимірний масив (матрицю) цілих чисел A[m,n]. Відсортувати окремо кожен рядок масиву **методом Шелла** **за незменшенням**. |

## 2. Роздруківка коду

```
#include <stdio.h>
#define RYADKIV 7
#define STOVPCHIKIV 8

void vivestiMatrizu(int A[RYADKIV][STOVPCHIKIV]) {
    for (int i = 0; i < RYADKIV; i++) {
        for (int j = 0; j < STOVPCHIKIV; j++) {
            printf("%4d", A[i][j]);
        }
        printf("\n");
    }
    printf("\n");
}
int viznachitiStan(int A[RYADKIV][STOVPCHIKIV]) {
    int nezmenshennya = 1;
    int nezrostannya = 1;

    for (int i = 0; i < RYADKIV; i++) {
        for (int j = 0; j < STOVPCHIKIV - 1; j++) {
            if (A[i][j] > A[i][j + 1]) {
                nezmenshennya = 0;
            }
            if (A[i][j] < A[i][j + 1]) {
                nezrostannya = 0;
            }
        }
    }
    if (nezmenshennya) {
        return 1;
    }
    if (nezrostannya) {
        return -1;
    }
    return 0;
}
void sortShellom(int A[RYADKIV][STOVPCHIKIV]) {
    for (int ryadok = 0; ryadok < RYADKIV; ryadok++) {
        for (int krok = STOVPCHIKIV / 2; krok > 0; krok /= 2) {
            for (int i = krok; i < STOVPCHIKIV; i++) {
                int potochniy = A[ryadok][i];
                int j = i;
                while (j >= krok && A[ryadok][j - krok] > potochniy) {
                    A[ryadok][j] = A[ryadok][j - krok];
                    j -= krok;
                }
                A[ryadok][j] = potochniy;
            }
        }
    }
}
int main() {
    int A[RYADKIV][STOVPCHIKIV];
    printf("Vvedit elementi matrici (%dx%d):\n", RYADKIV, STOVPCHIKIV);
    for (int i = 0; i < RYADKIV; i++) {
        for (int j = 0; j < STOVPCHIKIV; j++) {
            scanf("%d", &A[i][j]);
        }
    }
    int stan = viznachitiStan(A);
    if (stan == 1) {
        printf("\nvje vidsortovana (za nezmenshennyam)\n");
    } else if (stan == -1) {
        printf("\noberneno vidsortovana\n");
    } else {
        printf("\nnevidsortovana\n");
    }
    printf("Pochatkova matrica:\n");
    vivestiMatrizu(A);
    sortShellom(A);
    printf("Vidsortovana matrica:\n");
    vivestiMatrizu(A);
    return 0;
}
```
