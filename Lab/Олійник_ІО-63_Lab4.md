## 1. Мета лабораторної роботи

Засвоєння теоретичного матеріалу та набуття практичних навичок розв'язання задачі пошуку заданої категорії елементів за допомогою різних алгоритмів методу двійкового пошуку у двовимірних масивах.

## 2. Постановка задачі

1. Написати програму розв'язання задачі пошуку (за варіантом) у двовимірному масиві (матриці) методом двійкового пошуку. Конкретний алгоритм двійкового пошуку (№1 або №2) задається варіантом завдання.
2. Розміри матриці m та n взяти самостійно в межах від 7 до 10.
3. При тестуванні програми підбирати такі вхідні набори значень матриці, щоб можна було легко відстежити коректність виконання пошуку, і щоб ця коректність була протестована для всіх можливих випадків. З метою тестування дозволяється використовувати матриці меншого розміру.
Мій номер у списку - 17, тому моя задача така:

| № | Завдання |
|---|---|
|17|Задано матрицю дійсних чисел A[m,n]. Окремо у кожному стовпчику матриці визначити присутність будь-якого з чисел діапазону [0,5] і його місцезнаходження (координати) методом двійкового пошуку (**Алгоритм №1**), якщо елементи кожного стовпчика окремо впорядковані за незбільшенням. |

## 3.Код
```
#include <stdio.h>

int main() {
    int m = 7;
    int n = 7;

    double A[7][7] = {
         { 11.2,  4.0, 14.5, -0.2,  9.9, 12.0,  5.0 },
         {  9.4,  4.0, 10.2, -1.5,  8.7, 10.5,  3.8 },
         {  7.1,  4.0,  7.8, -3.0,  7.5,  8.2,  2.4 },
         {  3.3,  2.1,  5.2, -4.4,  6.1,  6.0,  1.9 },
         {  3.3,  1.0, -0.4, -5.8,  5.4,  5.3,  1.2 },
         {  0.8, -1.2, -2.9, -7.1,  1.5,  5.1,  0.5 },
         { -2.5, -4.0, -6.3, -9.0,  1.5,  5.1,  0.0 }
    };

    printf("Vhidna matrice A [%d][%d]:\n", m, n);
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            printf("%6.1f ", A[i][j]);
        }
        printf("\n");
    }
    printf("\n");

    printf("Rezultati (poshuku chisel diapazonu [0, 5] v kojnomu stovpchiku):\n");
    for (int j = 0; j < n; j++) {
        int left = 0;
        int right = m - 1;
        int row = -1;

        while (left <= right) {
            int mid = (left + right) / 2;

            if (A[mid][j] >= 0.0 && A[mid][j] <= 5.0) {
                row = mid;
                break;
            }
            else if (A[mid][j] > 5.0) {
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }
        if (row != -1) {
            printf("Stovpchik %d: naideno chislo %.1f na [%d][%d]\n",
                   j, A[row][j], row, j);
        } else {
            printf("Stovpchik %d: chisel diapazonu [0, 5] nema \n", j);
        }
    }

    return 0;
}
```

## 6.Висновок

Під час виконання лабораторної я написала програму розв'язання задачі пошуку у двовимірному масиві (матриці) методом двійкового пошуку(а саме №1).Перевіривши роботу 3 рази з різними матрицями, програма працює коректно у всіх випадках і без помилок або визначає наявність чисел у діапазоні [0, 5](та коректно виводить їхні координати), або їх відсутність у стовпчику(і виводить повідомлення про це ). Через те,що використовується алгоритм №1, програма зупиняється одразу ж, як знайде число у діапазоні [0, 5](це помітно там,де у тестах повторюються елементи). Двійковий пошук є значно швидшим за лінійний
